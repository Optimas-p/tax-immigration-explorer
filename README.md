# Обозреватель путей легализации и гражданства (тестовая версия)

Статическая страница: Испания и Уругвай, пути получения статуса и гражданства по вашим ответам,
раздел «Теория» с первоисточниками и раздел «Ребёнок».

- Всё считается прямо в браузере. Ваши ответы никуда не отправляются, они хранятся только в
  адресной строке страницы.
- **Это не юридическая консультация.** Данные собраны из открытых источников и не проверены
  юристом (`agent_draft`). Перед решением уточняйте условия в официальных документах.
- Это тестовая версия: об ошибках и неясностях сообщайте тому, кто дал вам ссылку.
